# NEXTZEN Classes & Computer Academy Website

A modern, responsive, and professional education website built using HTML5, CSS3, and Vanilla JavaScript.

## Features
- Clean, modern, and attractive design
- Fully responsive on all devices (mobile, tablet, desktop)
- Vanilla HTML/CSS/JS (No frameworks)
- Semantic HTML and accessibility features
- Dynamic admission form
- Custom CSS variables for easy branding adjustments

## Structure
- /index.html - Homepage with highlights and overview
- /about.html - About the academy's vision and mission
- /classes.html - Information on academic classes (KG to 10th)
- /computer-courses.html - Detailed computer courses, pricing, and comparison
- /admission.html - Enquiry form with dynamic class/course selection
- /contact.html - Contact information and placeholders for maps/address
- /css/style.css - All styling, responsive rules, animations
- /js/script.js - Mobile menu, sticky header, scroll reveal, form logic
- /assets/ - Logo and placeholder images

## Usage
Simply open index.html in any modern web browser.
